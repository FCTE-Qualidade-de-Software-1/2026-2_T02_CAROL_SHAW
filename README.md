# Avaliação de Qualidade de Software – Equipe Carol Shaw (2026.2)

## Sobre o Projeto

Este repositório compõe o trabalho final da disciplina **Qualidade de Software do semestre 2026.2**, ministrada pela professora Cristiane Soares Ramos na Universidade de Brasília (UnB – FCTE). O objetivo é avaliar aspectos de qualidade do [**DF no Ponto**](https://dfnoponto.com.br/), A partir dessa análise, busca-se propor melhorias fundamentadas em métricas, testes, inspeções e outras práticas de garantia de qualidade de software.
