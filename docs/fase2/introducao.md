## Introdução

Esta fase estabelece o planejamento de medição para o aplicativo DF no Ponto utilizando a abordagem Goal-Question-Metric (GQM). O objetivo é desdobrar os requisitos de qualidade identificados na Fase 1 (Portabilidade, Confiabilidade e Adequação Funcional) em metas claras, questões operacionais, hipóteses e métricas quantificáveis, fornecendo uma base objetiva para os julgamentos e testes subsequentes.
